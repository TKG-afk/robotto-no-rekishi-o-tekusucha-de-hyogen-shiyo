# ロボットの歴史を、テクスチャで表現しよう！

専門学校国際理工カレッジ ゲームクリエイター科1年生向けの Adobe Substance 3D Painter 入門授業です。共通のロボットモデルを題材に、全10枚で経年変化の観察からテクスチャの設計まで扱います。

## 起動方法

1. このフォルダ一式をPCに置き、`index.html` を Chrome または Edge で開きます。
2. プロジェクターなどに表示し、`F` キーか右下の「全画面」を押します。画面に収まる大きさで16:9を維持します。
3. 写真をクリックすると全体を拡大できます。`Esc` でスライドに戻ります。

起動用のサーバーやインストールは不要です。授業中はオフラインでスライドと写真を表示できます。写真の出典や外部のライセンス本文を開くにはインターネット接続が必要です。

| 操作 | キー・ボタン |
| --- | --- |
| 次へ | →・Space・PageDown、画面の「次へ」 |
| 前へ | ←・PageUp、画面の「前へ」 |
| 最初・最後へ | Home・End |
| 全画面表示の切り替え | F、画面の「全画面」 |
| 写真の拡大・終了 | 写真をクリック、Escで閉じる |

最後で「次へ」を押すと最初へ、最初で「前へ」を押すと最後へ移動します。

## 授業内容や写真を更新する場合

- `lesson.js` に5つの制作設定、比較表、Painterの機能説明、制作課題をまとめています。
- `app.js` は各スライドの組み立てと操作、`styles.css` は16:9のレイアウトと投影用の色・文字サイズを管理します。
- `assets/` に15枚の実写を保存しています。`photos.js` は説明、作者、ライセンス、掲載ページ、元画像URL、取得に使用したURLを管理します。
- `credits.html` またはスライド左下の「写真クレジット」から出典一覧が開きます。表紙と観察スライドでは、設定ページの写真を再掲しています。
